Home Assistant |Chat Status|
=================================================================================

Open-source home automation that puts local control and privacy first. Powered by a worldwide community of tinkerers and DIY enthusiasts, Home Assistant is perfect for running on a Raspberry Pi or a local server.

Visit `home-assistant.io <https://home-assistant.io>`__ to explore the platform, try the `live demo <https://demo.home-assistant.io>`__, follow the `installation instructions <https://home-assistant.io/getting-started/>`__, learn from the `automation tutorials <https://home-assistant.io/getting-started/automation/>`__, and browse the `documentation <https://home-assistant.io/docs/>`__.

Home Assistant uses a modular architecture that makes it easy to add support for new devices, services, and actions. Learn more about the `architecture <https://developers.home-assistant.io/docs/architecture_index/>`__ and explore the guide to `creating your own components <https://developers.home-assistant.io/docs/creating_component_index/>`__.

Need help? If you encounter issues while using Home Assistant or developing a component, visit the `Home Assistant help section <https://home-assistant.io/help/>`__ for troubleshooting guidance and further information.
